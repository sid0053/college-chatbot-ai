# Intelligent Campus Information Chatbot

A Flask-powered Python web application designed to parse, route, and resolve student queries regarding university schedules, guidelines, and campus events.

## Features & Tech Stack
- **Backend Environment:** Python 3, Flask Web Framework
- **Data Routing:** Implemented conditional search routing matrices to execute response templates
- **Database Engine:** Local JSON structures and internal dictionary mappings
- **Front-End Layout:** Native HTML5 and CSS3 user interface structures
